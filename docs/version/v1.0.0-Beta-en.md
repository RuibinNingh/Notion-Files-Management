# 🎉 v1.0.0 - First Official Release

**This is the first stable release of Notion Files Management!** 🚀

## ✨ Key Features

### 📥 Batch Download

- Automatically fetch Notion page file list
- Intelligent file size detection
- Multi-threaded concurrent download
- Real-time progress and speed display
- Support for task persistence when switching pages

### 📤 Batch Upload

- Batch select files for upload
- Automatic chunked upload (15MB/chunk)
- Built-in rate limit protection
- EMA smoothed speed display
- Support for task persistence when switching pages

### 🔧 Other Features

- Page file information statistics
- Flexible concurrency configuration
- Token secure management
- Version updates
- Detailed operation logs

## 🎯 Highlights of This Version

- ✅ **Session Persistence**: Tasks are not lost when switching pages
- ✅ **URL Expiry Detection**: Automatically detect and alert for URL expiration
- ✅ **Smooth Speed Display**: EMA algorithm avoids speed number fluctuations
- ✅ **Modern UI**: Clean interface based on WPF-UI

## 📦 Download

Notion-Files-Management v1.0.0-Beta.exe

## 💻 System Requirements

- Windows 10 (1809) or later
- x64 architecture
- 2GB RAM (4GB recommended)

## 🚀 Quick Start

1. Create an Integration at [Notion Integrations](https://www.notion.so/my-integrations)
2. Copy the Token (starting with `secret_`)
3. Authorize the Integration in your Notion page
4. Open the tool, go to the "Settings" page to configure the Token
5. Start using!

## ⚠️ Known Limitations

- Only supports x64 Windows
- Tasks are not preserved after program restart (will be supported in future versions)
- Complies with Notion API rate limits (3 requests/second)
