# 🎉 Notion Files Management v1.0.0-Beta

> 这是 Notion Files Management 的**首个公开测试版本**。  
> Beta 阶段意味着核心功能已可用，但仍可能存在未知问题，欢迎反馈！

---

## ✨ 核心功能

### 📥 批量下载

- 自动获取 Notion 页面文件列表（无需手动复制链接）
- 智能文件大小探测（多线程 HEAD 请求并发探测）
- 可视化文件选择，支持全选/取消
- 多线程并发下载，可配置并发数（1 / 3 / 5 / 8）
- 实时进度 + 下载速度 + 预计剩余时间
- **页面切换不丢失任务**（DownloadSession 单例保持状态）

### 📤 批量上传

- 批量选择本地文件上传至指定 Notion 页面
- 自动分片上传（15 MB / 片），兼容 Notion API 限制
- 内置速率限制保护，避免触发 429 错误
- EMA 平滑算法，速度显示稳定不跳动
- **页面切换不丢失任务**（UploadSession 单例保持状态）

### 🔧 工具箱

- 探测并统计指定 Notion 页面的文件数量与总大小
- 适用于"上传前预估空间"等场景

### ⚙️ 设置

- Notion Integration Token 安全配置
- 自定义 Notion API 地址（代理/私有部署）
- 下载 / 上传并发数统一管理
- **检查版本更新**：一键检查服务端最新版本，展示更新日志并提供下载入口

## 🚀 快速开始

**第一步：获取 Notion Integration Token**

1. 打开 [Notion Integrations](https://www.notion.so/my-integrations)，点击「New integration」
2. 填写名称，选择关联的 Workspace，点击「Submit」
3. 复制 Internal Integration Secret（以 `ntn_` 开头）

**第二步：授权页面**

在需要操作的 Notion 页面右上角 → 「…」→「Add connections」→ 选择你的 Integration

**第三步：配置工具**

1. 解压下载的 ZIP，运行 `Notion-Files-Management.exe`
2. 点击左侧「设置」，粘贴 Token，点击「保存配置」
3. 进入「下载」或「上传」页面，填写 Page ID 开始使用

> **Page ID 在哪里？**  
> Notion 页面 URL 格式：`https://www.notion.so/页面名-{32位ID}`  
> 复制最后那段 32 位字母数字即可。

## ⚠️ 已知限制（Beta 阶段）

- 仅支持 **Windows x64**，暂不支持 macOS / Linux / ARM
- 程序重启后任务列表**不会持久化**（任务状态仅保存在内存中）
- 暂不支持**断点续传**（下载中断需重新开始）
- 上传速度受 Notion API 速率限制（约 3 req/s）影响，无法绕过
- 暂无**自动更新**机制，需手动前往设置页检查并下载新版本
