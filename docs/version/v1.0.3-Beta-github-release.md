### 🎉 **Notion Files Management v1.0.3-Beta**

这是 **Notion Files Management** 的更新版本，统一版本号管理并增强日志系统。

------

## ✨ **新功能与修复**

- **统一版本号管理系统**
  新增 `AppVersion` 类，统一管理应用版本号，版本号统一在 `.csproj` 中配置，确保版本显示一致性。
- **修复版本号显示不一致问题**
  修复了主页版本号显示不一致的问题，现在所有位置都使用统一的版本号来源。
- **新增 Python 后端日志功能**
  Python 后端现在支持完整的日志记录功能，日志文件格式为 `yyyyMMddHHmmss-Py.logs`，便于追踪 Python 端的运行状态。
- **统一日志管理**
  Python 和 C# 日志现在都保存在同一目录：
  `C:\Users\[用户名]\AppData\Local\NotionFilesManagement\logs\`
  便于统一查看和管理所有日志信息。

### 🎉 **Notion Files Management v1.0.3-Beta**

This is an updated version of **Notion Files Management**, unifying version management and enhancing the logging system.

------

## ✨ **New Features & Fixes**

- **Unified version management system**
  Added `AppVersion` class to centrally manage application version numbers. Version numbers are now configured in `.csproj`, ensuring consistent version display.
- **Fixed inconsistent version display**
  Fixed the issue where the version number displayed inconsistently on the main page. All locations now use a unified version source.
- **Added Python backend logging**
  The Python backend now supports full logging functionality. Log files are formatted as `yyyyMMddHHmmss-Py.logs`, making it easier to track Python-side runtime status.
- **Unified log management**
  Both Python and C# logs are now saved in the same directory:
  `C:\Users\[Username]\AppData\Local\NotionFilesManagement\logs\`
  This makes it easier to view and manage all log information in one place.

------

## 📦 **Download**

[Notion-Files-Management.v1.0.3-Beta.exe](https://github.com/RuibinNingh/Notion-Files-Management/releases)

## 💻 **System Requirements**

- Windows 10 (1809+) · x64
- Minimum 2 GB RAM

## 🚀 **Quick Start**

1. Create an Integration in Notion via [Notion Integrations](https://www.notion.so/my-integrations) and copy the Token (starts with `ntn_`).
2. In your Notion page → `…` → **Add connections** → Select your Integration.
3. Open the application → **Settings** → Paste the Token → Save → Start using.

------

## ⚠️ **Known Issues**

- Only supports Windows x64.
- Tasks are not persistent after restarting the program (memory-only storage).
- Breakpoint resume is not supported yet.
- No automatic update feature; updates must be checked manually.
