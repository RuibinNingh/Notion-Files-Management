### 🎉 **Notion Files Management v1.1.0-Beta**

这是 **Notion Files Management** 的重大更新版本，新增强大的外观自定义功能，优化用户界面体验，并修复了多个界面问题。

------

## ✨ **新功能与修复**

### 🎨 **外观自定义功能**

- **嵌入式颜色选择器（调色盘）**
  在设置页面集成了功能完整的颜色选择器，支持 HSV（色相、饱和度、亮度）和 RGB（红、绿、蓝）两种颜色空间选择。提供 24 种预设颜色快速选择，实时预览选择的颜色，显示十六进制颜色值和 RGB 值。

- **背景材质设置**
  支持两种窗口背景材质：云母材质（Mica）和亚克力材质（Acrylic）。亚克力材质支持不透明度调节（0% - 100%），让您可以根据个人喜好自定义窗口背景效果。

- **外观设置保存机制优化**
  外观设置现在需要手动保存，避免在保存其他设置时意外覆盖未保存的外观设置。提供"保存"和"保存并重启应用"两个按钮，让您灵活选择保存方式。

### 🐛 **界面优化与修复**

- **修复 TitleBar 图标和标题位置偏移问题**
  修复了主窗口 TitleBar 中图标和标题位置偏移的问题。通过设置正确的对齐方式、调整图标尺寸为 16x16（符合 Windows 11 标准），并优化负边距，确保图标和标题紧贴左侧，消除左侧空隙。

- **重构工具箱页面功能分类**
  优化了工具箱页面的功能分类，将"查看日志文件"和"报告错误"功能从"Notion 相关"块中移出，创建了新的"软件工具"功能块，使功能分类更加清晰合理。

- **UI 布局优化**
  将背景材质设置合并到外观设置的 Card 中，外观相关设置现在集中在一个区域，布局更加统一美观。

## 🚀 **快速开始**

1. 在 Notion 的 [Notion Integrations](https://www.notion.so/my-integrations) 创建 Integration，复制 Token（`ntn_` 开头）。
2. 在 Notion 页面 → `…` → **Add connections** → 选择你的 Integration。
3. 打开应用 → **设置** → 粘贴 Token → 保存 → 开始使用。

### 🎨 **自定义外观**

1. 打开应用 → **设置** → **外观**。
2. 使用颜色选择器选择您喜欢的主题色（支持 HSV 和 RGB 模式，或从 24 种预设颜色中选择）。
3. 选择背景材质：云母材质（Windows 11 原生效果）或亚克力材质（支持不透明度调节）。
4. 点击"保存"或"保存并重启应用"使设置生效。

## ⚠️ **已知问题**

- 仅支持 Windows x64。
- 程序重启后任务不会持久化（仅内存保存）。
- 暂不支持断点续传。
- 暂无自动更新功能，需手动检查更新。
- 部分外观设置（如主题色和背景材质）需要重启应用才能完全生效。

### 🎉 **Notion Files Management v1.1.0-Beta**

This is a major update of **Notion Files Management**, introducing powerful appearance customization features, optimizing user interface experience, and fixing multiple interface issues.

------

## ✨ **New Features & Fixes**

### 🎨 **Appearance Customization**

- **Inline Color Picker (Color Palette)**
  Integrated a fully functional color picker in the settings page, supporting both HSV (Hue, Saturation, Brightness) and RGB (Red, Green, Blue) color space selection. Provides 24 preset colors for quick selection, real-time preview of selected colors, and displays hexadecimal color values and RGB values.

- **Background Material Settings**
  Supports two window background materials: Mica and Acrylic. Acrylic material supports opacity adjustment (0% - 100%), allowing you to customize window background effects according to your preferences.

- **Optimized Appearance Settings Save Mechanism**
  Appearance settings now require manual saving to prevent accidentally overwriting unsaved appearance settings when saving other settings. Provides "Save" and "Save and Restart Application" buttons for flexible saving options.

### 🐛 **Interface Optimization & Fixes**

- **Fixed TitleBar Icon and Title Position Offset Issue**
  Fixed the issue where the icon and title in the main window TitleBar were offset. By setting correct alignment, adjusting icon size to 16x16 (Windows 11 standard), and optimizing negative margins, the icon and title are now flush against the left side, eliminating left gaps.

- **Refactored Tools Page Function Categories**
  Optimized the function categories on the tools page by moving "View Log Files" and "Report Error" functions out of the "Notion Related" block and creating a new "Software Tools" function block, making function categories clearer and more logical.

- **UI Layout Optimization**
  Merged background material settings into the appearance settings Card. Appearance-related settings are now centralized in one area, with a more unified and beautiful layout.

## 🚀 **Quick Start**

1. Create an Integration in Notion via [Notion Integrations](https://www.notion.so/my-integrations) and copy the Token (starts with `ntn_`).
2. In your Notion page → `…` → **Add connections** → Select your Integration.
3. Open the application → **Settings** → Paste the Token → Save → Start using.

### 🎨 **Customize Appearance**

1. Open the application → **Settings** → **Appearance**.
2. Use the color picker to select your preferred theme color (supports HSV and RGB modes, or choose from 24 preset colors).
3. Select background material: Mica (Windows 11 native effect) or Acrylic (supports opacity adjustment).
4. Click "Save" or "Save and Restart Application" to apply the settings.

------

## ⚠️ **Known Issues**

- Only supports Windows x64.
- Tasks are not persistent after restarting the program (memory-only storage).
- Breakpoint resume is not supported yet.
- No automatic update feature; updates must be checked manually.
- Some appearance settings (such as theme color and background material) require restarting the application to fully take effect.
