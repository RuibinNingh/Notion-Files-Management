### 🎉 **Notion Files Management v1.0.1-Beta**

这是 **Notion Files Management** 的更新版本，已修复一些问题并增加了新功能。

------

## ✨ **新功能与修复**

- **修复日志保存问题**
   打包后运行时，日志文件夹会自动创建并保存日志。
- **新增查看日志功能**
   工具箱中新增了“查看日志文件”入口，点击即可打开日志文件夹。
- **移除不必要的功能**
   删除了“图标与主题实验室”调试功能，简化了界面。

------

## 📦 **下载**

[Notion-Files-Management v1.0.1-Beta.exe](#)

> 内嵌 Python 3.11，**无需单独安装 Python**。

------

## 💻 **系统要求**

- Windows 10 (1809+) · x64
- 最低 2 GB RAM

------

## 🚀 **快速开始**

1. 在 [Notion Integrations](https://www.notion.so/my-integrations) 创建 Integration，复制 Token（`ntn_` 开头）。
2. 在 Notion 页面 → `…` → **Add connections** → 选择你的 Integration。
3. 打开应用 → **设置** → 粘贴 Token → 保存 → 开始使用。

------

## ⚠️ **已知问题**

- 仅支持 Windows x64。
- 程序重启后任务不会持久化（仅内存保存）。
- 暂不支持断点续传。
- 暂无自动更新功能，需手动检查更新。

### 🎉 **Notion Files Management v1.0.1-Beta**

This is an updated version of **Notion Files Management**, fixing several issues and introducing new features.

------

## ✨ **New Features & Fixes**

- **Fixed log saving issue**
   After packaging, the application will now automatically create a log folder and save logs when running.
- **Added log viewing feature**
   A new **“View Log Files”** entry has been added to the toolbox. Click it to open the log folder.
- **Removed unnecessary features**
   The **“Icon & Theme Lab”** debugging feature has been removed to simplify the interface.

------

## 📦 **Download**

[Notion-Files-Management v1.0.1-Beta.exe](#)

> Built-in Python 3.11, **no separate Python installation required**.

------

## 💻 **System Requirements**

- Windows 10 (1809+) · x64
- Minimum 2 GB RAM

------

## 🚀 **Quick Start**

1. Create an Integration in [Notion Integrations](https://www.notion.so/my-integrations) and copy the Token (starts with `ntn_`).
2. In your Notion page → `…` → **Add connections** → Select your Integration.
3. Open the application → **Settings** → Paste the Token → Save → Start using.

------

## ⚠️ **Known Issues**

- Only supports Windows x64.
- Tasks are not persistent after restarting the program (memory-only storage).
- Breakpoint resume is not supported yet.
- No automatic update feature; updates must be checked manually.
