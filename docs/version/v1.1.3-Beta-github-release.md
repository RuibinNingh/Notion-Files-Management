### 🎉 **Notion Files Management v1.1.3-Beta**

这是 **Notion Files Management** 的更新版本，本次更新主要引入了全新的品牌视觉设计，更新了应用图标及相关 UI 元素，提升了产品的辨识度。

------

## ✨ **新功能与修复**

### 🎨 **视觉更新 (Visual Update)**

- **全新应用图标**
  - 设计并应用了全新的应用图标，风格更现代，更符合审美。
  - 更新了任务栏、窗口标题栏以及系统托盘的图标显示。
  - 优化了图标在不同缩放比例（DPI）下的清晰度。
- **UI 细节优化**
  - 更新了关于页面的 Logo 展示。
  - 微调了部分界面元素的间距，使其与新图标的视觉风格更加统一。

### 🐛 **修复与改进**

- **性能小幅提升**
  - 优化了图标资源的加载方式，减少了应用启动时的资源占用。
  - 修正了在某些 Windows 版本下图标显示模糊的问题。

------

## 📦 **下载**

[Notion-Files-Management.v1.1.3-Beta.exe](https://github.com/RuibinNingh/Notion-Files-Management/releases)

> 内嵌 Python 3.11，**无需单独安装 Python**。

------

## 💻 **系统要求**

- Windows 10 (1809+) · x64
- 最低 2 GB RAM

------

## 🚀 **快速开始**

1. 在 Notion 的 [Notion Integrations](https://www.notion.so/my-integrations) 创建 Integration，复制 Token（`ntn_` 开头）。
2. 在 Notion 页面 → `…` → **Add connections** → 选择你的 Integration。
3. 打开应用 → **设置** → 粘贴 Token → 保存 → 开始使用。

------

## ⚠️ **已知问题**

- 仅支持 Windows x64。
- 程序重启后任务不会持久化（仅内存保存）。
- 暂不支持断点续传。
- 暂无自动更新功能，需手动检查更新。
- 部分外观设置（如主题色和背景材质）需要重启应用才能完全生效。

### 🎉 **Notion Files Management v1.1.3-Beta**

This is an update of **Notion Files Management**, primarily introducing a brand-new visual identity with updated application icons and UI elements to enhance product recognition.

------

## ✨ **New Features & Fixes**

### 🎨 **Visual Update**

- **Brand New Application Icon**
  - Designed and implemented a new app icon with a modern style that aligns better with the Notion ecosystem.
  - Updated icons in the taskbar, window title bar, and system tray.
  - Optimized icon clarity across various display scaling (DPI) settings.
- **UI Refinement**
  - Updated the Logo display on the "About" page.
  - Slightly adjusted the spacing of UI elements to match the visual style of the new icon.

### 🐛 **Fixes & Improvements**

- **Minor Performance Boost**
  - Optimized the loading method for icon resources, reducing overhead during app startup.
  - Fixed an issue where the icon appeared blurry on certain Windows versions.

## 📦 **Download**

[Notion-Files-Management.v1.1.3-Beta.exe](https://github.com/RuibinNingh/Notion-Files-Management/releases)

------

## 💻 **System Requirements**

- Windows 10 (1809+) · x64
- Minimum 2 GB RAM

------

## 🚀 **Quick Start**

1. Create an Integration in Notion via [Notion Integrations](https://www.notion.so/my-integrations) and copy the Token (starts with `ntn_`).
2. In your Notion page → `…` → **Add connections** → Select your Integration.
3. Open the application → **Settings** → Paste the Token → Save → Start using.

------

## ⚠️ **Known Issues**

- Only supports Windows x64.
- Tasks are not persistent after restarting the program (memory-only storage).
- Breakpoint resume is not supported yet.
- No automatic update feature; updates must be checked manually.
- Some appearance settings (such as theme color and background material) require restarting the application to fully take effect.
