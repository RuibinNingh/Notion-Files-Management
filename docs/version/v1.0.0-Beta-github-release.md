# 🎉 Notion Files Management v1.0.0-Beta

这是 Notion Files Management 的**首个公开测试版本**。核心功能已可用，欢迎体验并反馈问题！

## ✨ 核心功能

**📥 批量下载** · 自动获取文件列表 · 并发探测文件大小 · 多线程下载 · 实时速度与进度

**📤 批量上传** · 多文件批量选择 · 自动分片（15 MB/片）· 内置限流保护 · EMA 平滑速度

**🔧 工具箱** · 探测页面文件信息与总大小统计

**⚙️ 设置** · Token 配置 · 并发数管理 · 检查版本更新（含更新日志展示）

## 🆕 首版亮点

- 🔄 **会话持久化** — 切换页面不中断任务
- ⚡ **GIL 安全并发** — 稳定无死锁的 Python 多线程调用
- 🎨 **Fluent Design UI** — WPF-UI 4.2，Windows 11 Mica 磁力效果
- 🔔 **版本自检** — 支持 Beta / Stable 状态感知的智能版本比较

## 📦 下载

Notion-Files-Management v1.0.0-Beta.exe

> 
>
> 内嵌 Python 3.11，**无需单独安装 Python**。

## 💻 系统要求

Windows 10 (1809+) · x64 · 最低 2 GB RAM

## 🚀 快速开始

1. 在 [Notion Integrations](https://www.notion.so/my-integrations) 创建 Integration，复制 Token（`ntn_` 开头）
2. 在目标 Notion 页面 → `…` → **Add connections** → 选择你的 Integration
3. 打开工具 → **设置** → 粘贴 Token → 保存 → 开始使用

**Page ID 在哪里？** Notion 页面 URL 最后的 32 位字母数字即是。

## ⚠️ 已知限制

- 仅支持 Windows x64
- 程序重启后任务不持久化（仅内存保存）
- 暂不支持断点续传
- 暂无自动更新，请前往设置页手动检查

# 🎉 Notion Files Management v1.0.0-Beta (English)

This is the **first public beta release**. Core features are ready — try it out and share your feedback!

## ✨ Features

**📥 Batch Download** · Auto-fetch file list · Concurrent size probing · Multi-threaded download · Live speed & ETA

**📤 Batch Upload** · Multi-file selection · Auto-chunked (15 MB/chunk) · Built-in rate limiting · Smooth EMA speed

**🔧 Toolbox** · Probe page file info and total size

**⚙️ Settings** · Token config · Concurrency control · In-app update checker with changelog

## 🆕 Highlights

- 🔄 **Session Persistence** — tasks survive page navigation
- ⚡ **GIL-Safe Concurrency** — stable Python multithreading via SemaphoreSlim
- 🎨 **Fluent Design UI** — WPF-UI 4.2, Mica backdrop on Windows 11
- 🔔 **Smart Version Check** — Beta/Stable-aware update comparison

## 📦 Downloads

Notion-Files-Management v1.0.0-Beta.exe

> Include embedded Python 3.11 — **no separate Python install needed**.

## 💻 Requirements

Windows 10 (1809+) · x64 · 2 GB RAM minimum

## 🚀 Quick Start

1. Create an Integration at [Notion Integrations](https://www.notion.so/my-integrations), copy the Token (`ntn_…`)
2. On your Notion page → `…` → **Add connections** → select your Integration
3. Open the app → **Settings** → paste Token → Save → start using

**Where's the Page ID?** It's the 32-char string at the end of your Notion page URL.

## ⚠️ Known Limitations

- Windows x64 only
- Tasks don't persist across restarts (in-memory only)
- No resume / partial download support yet
- No auto-update — check manually via Settings
