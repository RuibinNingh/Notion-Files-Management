### 🎉 **Notion Files Management v1.1.2-Beta**

这是 **Notion Files Management** 的更新版本，主要进行了系统性的代码重构和优化，提升了代码质量和可维护性。

------

## ✨ **新功能与修复**

### 🔧 **代码重构与优化**

- **SettingsPage 重构**
  - 提取了 `SaveBasicConfig()` 方法，统一处理基础配置（Token、URL、并发数）的保存逻辑
  - 提取了 `SaveAppearanceSettings()` 方法，统一处理外观设置（主题色、背景材质）的保存逻辑
  - 简化了响应式布局代码，优化布局切换逻辑，提高代码可读性
  - 消除了约 50 行重复代码，提高了代码可维护性

- **创建 PageIdInputHelper 辅助类**
  - 统一处理 PageId 输入框的格式化逻辑，消除了跨页面的重复代码
  - 在下载、上传、工具三个页面中统一使用，确保行为一致
  - 消除了约 60 行重复代码，后续修改只需修改一处

- **创建后端预热工具方法**
  - 在 `UiHelpers` 中新增 `WarmUpBackend()` 方法，统一处理后端预热逻辑
  - 简化了多个页面构造函数中的重复代码
  - 便于后续统一调整后端预热策略

### 🐛 **修复与改进**

- **代码质量提升**
  - 系统性地清理了项目中的冗余代码（约 125 行）
  - 提高了代码可维护性，修改公共逻辑只需修改一处
  - 代码结构更清晰，职责更明确
  - 所有功能保持完全兼容，不改变任何业务逻辑和功能行为

## 🚀 **快速开始**

1. 在 Notion 的 [Notion Integrations](https://www.notion.so/my-integrations) 创建 Integration，复制 Token（`ntn_` 开头）。
2. 在 Notion 页面 → `…` → **Add connections** → 选择你的 Integration。
3. 打开应用 → **设置** → 粘贴 Token → 保存 → 开始使用。

### 🎨 **自定义外观**

1. 打开应用 → **设置** → **外观**。
2. 使用颜色选择器选择您喜欢的主题色（支持 HSV 和 RGB 模式，或从 24 种预设颜色中选择）。
3. 选择背景材质：云母材质（Windows 11 原生效果）或亚克力材质（支持不透明度调节）。
4. 点击"保存"或"保存并重启应用"使设置生效。

## ✨ **New Features & Fixes**

### 🔧 **Code Refactoring & Optimization**

- **SettingsPage Refactoring**
  - Extracted `SaveBasicConfig()` method to unify the logic for saving basic configuration (Token, URL, concurrency)
  - Extracted `SaveAppearanceSettings()` method to unify the logic for saving appearance settings (theme color, background material)
  - Simplified responsive layout code, optimized layout switching logic, improved code readability
  - Eliminated approximately 50 lines of duplicate code, improved code maintainability

- **Created PageIdInputHelper Helper Class**
  - Unified the formatting logic for PageId input boxes, eliminating duplicate code across pages
  - Unified usage in download, upload, and tools pages to ensure consistent behavior
  - Eliminated approximately 60 lines of duplicate code, future modifications only need to be made in one place

- **Created Backend Warm-up Utility Method**
  - Added `WarmUpBackend()` method in `UiHelpers` to unify backend warm-up logic
  - Simplified duplicate code in multiple page constructors
  - Facilitates future unified adjustments to backend warm-up strategy

### 🐛 **Fixes & Improvements**

- **Code Quality Improvements**
  - Systematically cleaned up redundant code in the project (approximately 125 lines)
  - Improved code maintainability, modifications to common logic only need to be made in one place
  - Clearer code structure with more defined responsibilities
  - All functionality remains fully compatible, no changes to business logic or functional behavior

## 🚀 **Quick Start**

1. Create an Integration in Notion via [Notion Integrations](https://www.notion.so/my-integrations) and copy the Token (starts with `ntn_`).
2. In your Notion page → `…` → **Add connections** → Select your Integration.
3. Open the application → **Settings** → Paste the Token → Save → Start using.

### 🎨 **Customize Appearance**

1. Open the application → **Settings** → **Appearance**.
2. Use the color picker to select your preferred theme color (supports HSV and RGB modes, or choose from 24 preset colors).
3. Select background material: Mica (Windows 11 native effect) or Acrylic (supports opacity adjustment).
4. Click "Save" or "Save and Restart Application" to apply the settings.

------

## ⚠️ **Known Issues**

- Only supports Windows x64.
- Tasks are not persistent after restarting the program (memory-only storage).
- Breakpoint resume is not supported yet.
- No automatic update feature; updates must be checked manually.
- Some appearance settings (such as theme color and background material) require restarting the application to fully take effect.
