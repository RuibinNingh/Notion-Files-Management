### 🎉 **Notion Files Management v1.2.0-Beta**

这是 **Notion Files Management** 的功能更新版本，新增自定义图片/视频背景支持、下载链接过期自动刷新机制，以及大量内部优化和 Bug 修复。

------

## ✨ **新功能与修复**

### 🖼️ **自定义图片/视频背景**

- 背景材质新增"图片"选项
  - 支持自定义图片（PNG/JPG/BMP/GIF）或视频（MP4）作为应用背景。
  - 可通过滑动条调节模糊度（0-50px）和不透明度（0%-100%）。
  - 视频背景支持循环播放、静音。
  - 无效路径或不支持的格式自动回退到云母（Mica）模式。

### 🔄 **下载链接过期自动刷新**

- 下载过程中链接过期无需手动重新获取
  - 下载时检测到 HTTP 401/403/410 错误后，自动通过 Notion API 刷新文件链接并重试（最多 2 次）。
  - 新增 `"refreshing"` 下载状态指示，刷新成功后自动继续下载。
  - 无需用户干预，大幅改善大批量长时间下载的体验。

### 🔧 **设置页面排版优化**

- 贪心高度平衡自动排版
  - 重构设置页面布局系统，将所有设置区块通过贪心算法动态分配到两列，确保两列高度接近。
  - 将"外观"大卡片拆分为"主题色"和"背景材质"两个独立卡片，提升布局灵活性。
  - 子面板展开/折叠时自动重新平衡布局。

### 🐛 **修复与改进**

- 修复设置页面鼠标滚轮无法滚动的问题
  - 定位根因：WPF-UI NavigationView 内部已有 ScrollViewer 包裹页面，嵌套 ScrollViewer 导致内层 ScrollableHeight 始终为 0。
  - 移除内嵌 ScrollViewer，改为运行时发现并驱动祖先 ScrollViewer 滚动。
  - 使用 `AddHandler(handledEventsToo: true)` 确保 Slider/ComboBox 不会吞掉滚轮事件。
- 修复「保存并重启应用」按钮无法重启的问题
  - 原因：`Assembly.GetExecutingAssembly().Location` 在单文件发布模式下返回空字符串。
  - 改用 `Environment.ProcessPath`（.NET 6+），兼容所有发布模式。
  - 应用退出时增加 Python 引擎关闭的异常保护，避免重启流程挂起。
- 冗余代码清理
  - 移除 7 个不再使用的死代码文件（旧对话框窗口、调试页面等）。
  - 移除 ConfigData.AppVersion 遗留属性、Logger 未使用方法、PythonBackendHost 未调用重载等。

### 🎉 **Notion Files Management v1.2.0-Beta**

This is a feature update of **Notion Files Management**, introducing custom image/video background support, automatic download link refresh on expiration, and numerous internal optimizations and bug fixes.

------

## ✨ **New Features & Fixes**

### 🖼️ **Custom Image/Video Background**

- New "Image" option in background material settings
  - Supports custom images (PNG/JPG/BMP/GIF) or videos (MP4) as the application background.
  - Adjustable blur (0-50px) and opacity (0%-100%) via sliders.
  - Video backgrounds play on loop with sound muted.
  - Invalid paths or unsupported formats automatically fall back to Mica mode.

### 🔄 **Automatic Download Link Refresh on Expiration**

- No need to re-fetch the list when download links expire
  - Automatically detects HTTP 401/403/410 errors during download, refreshes file URLs via the Notion API, and retries (up to 2 times).
  - New `"refreshing"` download status indicator; download resumes automatically after a successful refresh.
  - No user intervention required — greatly improves the experience for large, long-running batch downloads.

### 🔧 **Settings Page Layout Optimization**

- Greedy height-balanced auto layout
  - Refactored the settings page layout system. All setting sections are dynamically distributed into two columns using a greedy algorithm to balance column heights.
  - Split the single "Appearance" card into separate "Theme Color" and "Background Material" cards for finer layout control.
  - Automatic re-balancing when sub-panels expand or collapse.

### 🐛 **Fixes & Improvements**

- Fixed mouse wheel scrolling not working on the settings page
  - Root cause: WPF-UI's NavigationView internally wraps page content with a ScrollViewer; nesting another ScrollViewer caused the inner one to have ScrollableHeight = 0.
  - Removed the nested ScrollViewer; now discovers and drives the ancestor ScrollViewer at runtime.
  - Uses `AddHandler(handledEventsToo: true)` to prevent Slider/ComboBox from swallowing wheel events.
- Fixed "Save and Restart" button failing to restart the application
  - Cause: `Assembly.GetExecutingAssembly().Location` returns an empty string in single-file publish mode.
  - Replaced with `Environment.ProcessPath` (.NET 6+), compatible with all publish modes.
  - Added exception handling for Python engine shutdown during exit to prevent the restart process from hanging.
- Dead code cleanup
  - Removed 7 unused dead code files (legacy dialog windows, debug pages, etc.).
  - Removed ConfigData.AppVersion legacy property, unused Logger methods, uncalled PythonBackendHost overloads, and more.
