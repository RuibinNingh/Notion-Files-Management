### 🎉 **Notion Files Management v1.1.1-Beta**

这是 **Notion Files Management** 的更新版本，主要优化了设置页面的响应式布局，提升了用户界面体验。

------

## ✨ **新功能与修复**

### 🎨 **界面优化**

- **设置页面响应式布局优化**
  设置页面现在支持响应式布局，可以根据窗口大小自动调整布局方式：
  - 当窗口宽度 ≥ 1200px 时，内容分布在两列中（左侧：Notion 服务配置和任务并发设置；右侧：外观设置和关于）
  - 当窗口宽度 < 1200px 时，自动切换为单列布局，所有内容垂直排列
  - 充分利用屏幕空间，避免大窗口时右侧出现空白
  - 布局切换流畅，无闪烁

### 🐛 **修复与改进**

- **优化窗口空间利用**
  移除了固定宽度限制，改为根据窗口大小自适应，让设置页面在不同窗口尺寸下都能充分利用屏幕空间。

[Notion-Files-Management.v1.1.1-Beta.exe](https://github.com/RuibinNingh/Notion-Files-Management/releases)

## 💻 **系统要求**

- Windows 10 (1809+) · x64
- 最低 2 GB RAM

## 🚀 **快速开始**

1. 在 Notion 的 [Notion Integrations](https://www.notion.so/my-integrations) 创建 Integration，复制 Token（`ntn_` 开头）。
2. 在 Notion 页面 → `…` → **Add connections** → 选择你的 Integration。
3. 打开应用 → **设置** → 粘贴 Token → 保存 → 开始使用。

### 🎨 **自定义外观**

1. 打开应用 → **设置** → **外观**。
2. 使用颜色选择器选择您喜欢的主题色（支持 HSV 和 RGB 模式，或从 24 种预设颜色中选择）。
3. 选择背景材质：云母材质（Windows 11 原生效果）或亚克力材质（支持不透明度调节）。
4. 点击"保存"或"保存并重启应用"使设置生效。

------

## ⚠️ **已知问题**

- 仅支持 Windows x64。
- 程序重启后任务不会持久化（仅内存保存）。
- 暂不支持断点续传。
- 暂无自动更新功能，需手动检查更新。
- 部分外观设置（如主题色和背景材质）需要重启应用才能完全生效。

### 🎉 **Notion Files Management v1.1.1-Beta**

This is an update of **Notion Files Management**, primarily optimizing the responsive layout of the settings page and improving the user interface experience.

------

## ✨ **New Features & Fixes**

### 🎨 **Interface Optimization**

- **Settings Page Responsive Layout Optimization**
  The settings page now supports responsive layout, automatically adjusting the layout based on window size:
  - When window width ≥ 1200px, content is distributed in two columns (left: Notion service configuration and task concurrency settings; right: appearance settings and about)
  - When window width < 1200px, automatically switches to single-column layout with all content arranged vertically
  - Fully utilizes screen space, avoiding blank space on the right side in large windows
  - Smooth layout transitions without flickering

### 🐛 **Fixes & Improvements**

- **Optimized Window Space Utilization**
  Removed fixed width limitations, changed to adaptive sizing based on window size, allowing the settings page to fully utilize screen space at different window sizes.

## 🚀 **Quick Start**

1. Create an Integration in Notion via [Notion Integrations](https://www.notion.so/my-integrations) and copy the Token (starts with `ntn_`).
2. In your Notion page → `…` → **Add connections** → Select your Integration.
3. Open the application → **Settings** → Paste the Token → Save → Start using.

### 🎨 **Customize Appearance**

1. Open the application → **Settings** → **Appearance**.
2. Use the color picker to select your preferred theme color (supports HSV and RGB modes, or choose from 24 preset colors).
3. Select background material: Mica (Windows 11 native effect) or Acrylic (supports opacity adjustment).
4. Click "Save" or "Save and Restart Application" to apply the settings.

------

## ⚠️ **Known Issues**

- Only supports Windows x64.
- Tasks are not persistent after restarting the program (memory-only storage).
- Breakpoint resume is not supported yet.
- No automatic update feature; updates must be checked manually.
- Some appearance settings (such as theme color and background material) require restarting the application to fully take effect.
