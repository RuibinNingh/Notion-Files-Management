### 🎉 **Notion Files Management v1.3.0-Status**

这是 **Notion Files Management** 的正式版功能更新，新增数据源迁移和批量去除页面标题后缀功能，版本状态从 Beta 升级为 Status（正式版）。

------

## ✨ **新功能**

### 🔄 **数据源迁移**

- 工具箱新增「数据源迁移」功能
  - 将源数据源的所有页面按属性映射批量同步属性值到目标数据源（仅同步属性，不含页面内容）。
  - 支持属性映射配置：选择源属性与目标属性的对应关系，自动跳过只读属性。
  - 基于标题匹配的属性同步方案，配合 Notion 原生复制粘贴使用。
  - 多线程并发执行，内置 Notion API 速率限制保护。
  - 3 步交互流程：输入数据源 ID → 属性映射 → 进度监控。
  - 实时显示迁移进度（总计/成功/失败），支持取消操作。

### ✂️ **批量去除页面标题后缀**

- 工具箱新增「批量去除后缀」功能
  - 批量去除数据库页面标题中的指定后缀（如 `(1)`、` - Copy`、`_backup` 等）。
  - 用户自定义后缀内容，精确匹配标题末尾。
  - 去除后缀后自动 trim 右侧空格，标题为空时自动跳过（安全保护）。
  - 多线程并发处理，支持取消操作。
  - 实时显示扫描数、匹配数、成功数、失败数。

------

## 🔧 **技术变更**

### Python 后端

- 使用 Notion API 2025-09-03 Data Sources API（`/v1/data_sources`）。
- `notion.py` 新增 `get_database_properties()`、`query_database()`、`create_page_in_database()`、`append_blocks()`、`move_page()`、`update_page_properties()` 方法。
- 新增 `migrate.py` 模块（`MigrationTask` + `ThreadPoolExecutor` 多线程）。
- 新增 `batch_rename.py` 模块（`BatchRemoveSuffixTask` + `ThreadPoolExecutor` 多线程）。
- `main.py` 新增迁移和批量去除后缀相关的 6 个入口方法。

### C# 前端

- `NotionBackendService` 新增迁移和批量去除后缀的门面方法。
- `ToolsPage` 新增迁移 3 步交互弹窗和去除后缀 2 步交互弹窗。

<a name="english"></a>

### 🎉 **Notion Files Management v1.3.0-Status**

This is a stable release of **Notion Files Management**, introducing data source migration and batch page title suffix removal features. The version status has been upgraded from Beta to Status (stable release).

------

## ✨ **New Features**

### 🔄 **Data Source Migration**

- New "Data Source Migration" tool in the Toolbox
  - Batch synchronize property values from all pages in a source data source to a target data source with property mapping (properties only, page content not included).
  - Configurable property mapping: select source-to-target property correspondences; read-only properties are automatically skipped.
  - Title-based matching approach for property synchronization, designed to work with Notion's native copy-paste workflow.
  - Multi-threaded execution with built-in Notion API rate limiting.
  - 3-step interactive flow: Enter data source IDs → Configure property mapping → Monitor progress.
  - Real-time progress display (total/success/failed) with cancel support.

### ✂️ **Batch Remove Page Title Suffix**

- New "Batch Remove Suffix" tool in the Toolbox
  - Batch remove a specified suffix from database page titles (e.g., `(1)`, ` - Copy`, `_backup`).
  - User-defined suffix with exact end-of-title matching.
  - Automatically trims trailing spaces after removal; skips pages where the result would be empty (safety protection).
  - Multi-threaded processing with cancel support.
  - Real-time display of scanned/matched/success/failed counts.

------

## 🔧 **Technical Changes**

### Python Backend

- Uses Notion API 2025-09-03 Data Sources API (`/v1/data_sources`).
- `notion.py`: Added `get_database_properties()`, `query_database()`, `create_page_in_database()`, `append_blocks()`, `move_page()`, `update_page_properties()`.
- New `migrate.py` module (`MigrationTask` + `ThreadPoolExecutor`).
- New `batch_rename.py` module (`BatchRemoveSuffixTask` + `ThreadPoolExecutor`).
- `main.py`: Added 6 new entry methods for migration and batch suffix removal.

### C# Frontend

- `NotionBackendService`: Added facade methods for migration and batch suffix removal.
- `ToolsPage`: Added 3-step migration dialog and 2-step suffix removal dialog.

## ⚠️ **Known Issues**

- Only supports Windows x64.
- Tasks are not persistent after restarting the program (memory-only storage).
- Breakpoint resume is not supported yet.
- No automatic update feature; updates must be checked manually.
- Data source migration uses title-based matching; pages with identical titles may cause imprecise mapping.
